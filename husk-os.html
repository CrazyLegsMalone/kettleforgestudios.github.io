Husk OS

A tiny operating system for tiny hardware. Husk OS brings a simple, customizable experience to ESP32-powered e-paper devices.

Previously developed as Lesion OS. Public core release in preparation.

Release statusExplore apps

Built for e-paper

Initial hardware target: Waveshare ESP32-S3 ePaper 1.54G V2, with a 200 × 200 four-color display and two-button navigation.

Keep the core clean

A small, stable foundation for navigation, device settings, battery information and Wi-Fi updates. Optional features stay optional.

Husk Apps

Make it your own

Official Husk Apps will also be free and open-source. Planned optional features include weather, internet radio, audio recording, alarms and PC telemetry.

An on-device app catalog is a future goal; installation methods will depend on the device's firmware and storage limitations.
